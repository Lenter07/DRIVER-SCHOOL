# Автошкола: учёт курсантов, занятий и оплат

Учебный проект по дисциплине «Базы данных».
База данных PostgreSQL `Driver-school` и веб-приложение на Flask для работы с ней.

## Возможности

- Главная: сумма договоров, оплачено, долг, ближайшие занятия, состав групп
- Просмотр, добавление, изменение и удаление записей по 8 таблицам:
  категории, инструкторы, автомобили, учебные группы, курсанты, занятия, договоры, платежи
- Запись курсанта на обучение: курсант и договор создаются одной формой
- Карточка курсанта: договоры, остаток к оплате, платежи, практика
- Отчёты: должники, свободные инструкторы, автомобили вне расписания, состав групп
- Поиск в списках и цветные статусы оплаты и занятий
- Правила базы (формат телефона и паспорта, возраст, конфликты расписания,
  лимит платежей) показываются в интерфейсе как сообщения об ошибках

## Состав репозитория

| Файл | Что это |
| --- | --- |
| `app.py` | приложение (Flask) |
| `requirements.txt` | зависимости Python |
| `schema.sql` | структура БД: домены, таблицы, индексы, триггеры, процедура |
| `data.sql` | тестовые данные (14 курсантов, 4 группы, 27 занятий, 14 договоров, 20 платежей) |
| `driver_school.sql` | готовый дамп: структура и данные в одном файле |

Для создания базы достаточно **одного из двух вариантов**: либо `driver_school.sql`,
либо `schema.sql` и затем `data.sql`.

## Требования

- Python 3.10 или новее
- PostgreSQL 14 или новее

## Подключение к базе

База `Driver-school`, кодировка UTF-8, хост `localhost`, порт `5432`.
Параметры подключения приложение берёт из переменной окружения `DATABASE_URL`:

```
postgres://ПОЛЬЗОВАТЕЛЬ:ПАРОЛЬ@localhost:5432/Driver-school
```

Пароль лучше задать без символов `@`, `#`, `/`: в адресе подключения их нужно кодировать.

## Как создать базу

### Windows (командная строка `cmd`, в папке проекта)

Путь к `bin` PostgreSQL подставьте свой.

```bat
set PATH=%PATH%;C:\Program Files\PostgreSQL\16\bin
set PGCLIENTENCODING=UTF8
psql -U postgres -c "CREATE DATABASE \"Driver-school\" ENCODING 'UTF8' LC_COLLATE 'C' LC_CTYPE 'C' TEMPLATE template0;"
psql -U postgres -d Driver-school -f driver_school.sql
```

Повторный запуск `schema.sql` удаляет таблицы вместе с данными и создаёт их заново.

## Как запустить приложение


### Windows

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
set DATABASE_URL=postgres://postgres:ПАРОЛЬ@localhost:5432/Driver-school
python -m flask --app app run
```

Приложение откроется по адресу http://127.0.0.1:5000

## Структура базы данных

Восемь таблиц: `categories`, `instructors`, `study_groups`, `cars`, `cadets`,
`lessons`, `contracts`, `payments`.

- справочники: категории, инструкторы, автомобили
- связи: группы, курсанты, занятия, договоры, платежи
- форматы данных заданы 18 доменами (`d_phone`, `d_plate`, `d_vin` и др.)
- расписание защищено частичными уникальными индексами
- статус оплаты договора пересчитывается триггерами при каждом изменении платежей
- договор оформляет процедура `sp_enroll_cadet`
